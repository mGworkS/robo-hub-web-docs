# Robo Hub web UI documentation

This repository develops the user interface specification for the Robo Hub learning platform through explicit product clarification. Documentation is maintained in English; the learning offer has German and English editions.

Start with the [UI concept and open questions](docs/en/ui-concept.md). It separates confirmed choices, inherited product requirements and questions still to be resolved. This is a planning document; it does not describe an implemented application.

| Source | Responsibility |
| --- | --- |
| [Learning platform](https://github.com/mGworkS/learning-platform-docs) | Product promise, audience and shared requirements |
| [Learning offer documentation](https://github.com/mGworkS/humanoid-pod-assets-docs/tree/main/docs/en) | Series, learning paths, content structure and editorial information |
| [Web application](https://github.com/mGworkS/robo-hub-web) | Future implementation |

Keep shared product and content definitions in their responsible repositories and link to them here. Record confirmed UI choices without silently promoting proposals or selecting an architecture.
